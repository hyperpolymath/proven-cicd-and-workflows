== Where this is going

Every estate repo calls ONE reusable workflow (`proven.yml`) from ONE small file,
and requires ONE check (`proven / verdict`). New categories, aspects and checks
are added here once and reach about 320 repos on the next pin bump. Nothing is
hand-wired per repo, and nothing passes on absence.

== Decisions taken (owner said "just go")

* One required check, `proven / verdict`, so adding runners never changes the ruleset.
* Waivers are explicit, expire, and show in the verdict (a transition tool, not a pass on absence).
* The first bench run needs `baselining = true` in the manifest; otherwise no history fails.
* Repo-wide N/A and language ignores need a written reason.
